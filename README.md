# Login &amp; Registration

A self-contained login and registration flow. Create an account, sign in, and
see inline form validation and session handling — a focused front-end demo of a
clean auth experience.

**Live demo:** https://humaidi.me/login/

## Built with

React 19 · Vite · Tailwind CSS v4 · React Router · Zustand · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (the app is served under `/login/`). Build for
production with `npm run build`.
